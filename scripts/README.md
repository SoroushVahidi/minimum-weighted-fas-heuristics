# Scripts

CLI entry points for algorithms and experiment runners.

| Script | Purpose |
|---|---|
| `run_lrta.py` | LR-TA heuristic |
| `run_wmsf.py` | WMSF-style seed |
| `run_ipsns.py` | IPSNS refinement |
| `run_exact.py` | Exact DP (small n) |

Run from repository root. See root `README.md` for examples.
