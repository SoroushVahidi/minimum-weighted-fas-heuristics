\subsection*{Data and code availability}
\textbf{Online Resource~1} (supplementary PDF and artifact archive) accompanies this submission. It contains: (i)~complete proofs deferred from the main text, including topological-extraction inequalities; (ii)~extended computational tables, EXP10 stochastic-robustness materials, and EXP11 extraction-sensitivity calibration; (iii)~the implementation (\texttt{src/mwfas/}), a 91-test automated correctness gate (90 passed, 1 skipped at freeze), and reproduction scripts; and (iv)~committed CSV/JSON summaries for reported experiments (EXP1b--EXP11). Public benchmark instances are cited in the manuscript; instance download and preprocessing steps are documented in OR1.

\textbf{Reproduction levels.} Level~A (smoke validation) and Level~B (test suite) complete in seconds on a standard workstation. Level~C regenerates principal manuscript tables from committed summaries without rerunning expensive benchmarks. Level~D (full benchmark reruns) is optional and documented but not required to verify the reported numbers.

\textbf{Command (Level~B):}
\begin{verbatim}
pip install -r requirements-dev.txt
PYTHONPATH=src python3 -m pytest tests/ -q
\end{verbatim}
Expected result when run from the full repository checkout: 90 passed, 1 skipped (91 collected). The OR1 artifact archive uses the same test tree; one EXP10 namespace test is skipped when the DRMacIver runner is inactive.

We do not claim machine-checked formal verification; the test suite provides regression and correctness coverage on tiny graphs with independent brute-force cross-checks.
