\section{Problem definition}
\label{sec:problem-definition}

Let \(G=(V,A,w)\) be a directed graph with nonnegative arc weights \(w:A\to \mathbb{R}_{\ge 0}\). A feedback arc set is a set of arcs whose removal makes the graph acyclic. The minimum weighted feedback arc set problem asks for a feedback arc set of minimum total weight.
