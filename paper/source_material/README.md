# Source Material

This directory records predecessor-manuscript inputs used for scaffold preparation.

- `bibtex/`: copied BibTeX files extracted from predecessor archives. These are committed for reference consolidation.
- `extracted_archives/`: local regenerated extraction of predecessor ZIP files. This directory is ignored because the archives already live under `archive/predecessor_projects/`.
- `tex_sources/`: local copied TeX sources used to generate the reusable-material audit. This directory is ignored to avoid committing predecessor manuscript text.

Derived maps and summaries are committed under `paper/notes/`.
