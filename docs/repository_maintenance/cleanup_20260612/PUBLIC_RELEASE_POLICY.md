# Public Release Policy

Repository is **private** during COAP submission preparation.

Before making the repository public:

1. Review `docs/archive/internal/` — editorial strategy material.
2. Confirm no rejection letters or confidential reviewer text in tracked files.
3. Scrub absolute paths in `experiments/coap_ipsns_holdout/results/runs.jsonl` if redistributing (optional sanitization pass).
4. Keep `docs/archive/legacy_submission_packages/` labeled stale or remove from default branch.
5. Ensure README points to OR1 for reproducibility, not stale EJCO zips.

Required disclosures in manuscript and cover letter remain in `paper_coap/submission/final_upload/`.
