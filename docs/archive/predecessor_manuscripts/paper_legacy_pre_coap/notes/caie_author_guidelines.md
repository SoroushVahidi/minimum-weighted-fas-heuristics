# CAIE Author Guidelines Notes

Working target: `Computers & Industrial Engineering` with double-anonymized Elsevier review preparation.

## Verified from official Elsevier policy pages

- Double-anonymized review requires a separate title page and a separate anonymized manuscript.
- The anonymized manuscript must omit author names, affiliations, acknowledgements, funding references, and identifying links.
- Highlights are 3--5 bullet points and each bullet must be 85 characters or fewer, including spaces.
- Generative AI use must be disclosed in a separate declaration section immediately before the references.
- CRediT statements are provided during submission and appear above the acknowledgment section in the published article.
- Data availability statements are handled through the submission flow and should explain how data or code can be accessed.

## Working manuscript assumptions for this scaffold

- Double-anonymized submission package: `main_anonymized.tex` plus separate `title_page.tex`.
- Elsevier `elsarticle` remains the class.
- Author-year bibliography is preferred for CAIE preparation, so this scaffold uses `elsarticle-harv`.
- The current scaffold keeps seven keywords, which matches the working 1--7 keyword assumption.
- Equations should be numbered consecutively.
- Tables should remain editable, avoid vertical rules and shading, and be cited in order.
- Figures should be supplied as separate files later, with captions and in-text citation order preserved.
- A graphical abstract is treated as optional for now and is intentionally not prepared in this pass.
- The manuscript should avoid AI-generated artwork.
- Data/code availability should point to an anonymized supplementary artifact during review and to a public archive after acceptance.
- CRediT, competing-interest, funding, and generative-AI declarations should be prepared now even if final metadata is completed at submission time.
