# CAIE Submission Checklist

- [x] Prepare a separate title page.
- [x] Prepare a separate anonymized manuscript.
- [x] Remove author names, affiliations, acknowledgements, and identifying links from the review manuscript.
- [x] Keep the abstract below 250 words in the current scaffold.
- [x] Keep keywords within the working 1--7 range.
- [x] Prepare 3--5 highlights with each bullet at most 85 characters.
- [ ] Verify CAIE-specific Guide for Authors requirements on highlights and abstract length.
- [x] Use consecutively numbered equations.
- [x] Keep tables editable and avoid vertical rules.
- [ ] Add final figure files and captions, cited in order.
- [x] Avoid AI-generated artwork.
- [x] Prepare an anonymized data/code availability statement.
- [x] Prepare a CRediT statement placeholder.
- [x] Prepare a competing-interest statement.
- [x] Prepare a funding statement.
- [x] Prepare a generative-AI declaration.
- [ ] Finalize a public repository link and archival DOI after acceptance.
- [ ] Verify title-page metadata and corresponding-author details before submission.
