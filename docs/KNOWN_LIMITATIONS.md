# Known Limitations

- **Nonnegative weights only** in standard comparisons; negative-weight instances excluded.
- **Sparse digraph focus**; LOLIB dense transfer shows scope boundary (DRMacIver stronger on many dense instances).
- **Scoped baseline claims** — “among evaluated methods”; two primary external baselines (DRMacIver/FAS, igraph Eades).
- **EXP10** — quality-focused repeated-run study; not equal-time comparison.
- **Holdout** — supports engineering defaults, not universal parameter optimality.
- **Reproducibility** — full benchmark reruns require external datasets and DRMacIver binary; OR1 provides summaries and table-regeneration scripts.
- **Private repository** — Online Resource 1 is the submission reproducibility artifact.
