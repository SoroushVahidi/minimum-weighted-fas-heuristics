## Is a related-manuscript statement required at initial COAP submission?

**Assessment:** COAP / Springer Nature does not mandate a separate related-manuscript statement document at initial submission for standard original research articles. The concurrent-submission declaration in the cover letter satisfies the standard ethical disclosure requirement.

The portal may have an optional "Related manuscripts" free-text field — this is handled by the editor-only portal text in EDITORIAL_MANAGER_FINAL_COPY_READY_TEXT.md.

---

## Upload recommendation

**DO NOT upload** `Vahidi_Related_Manuscripts_Statement.pdf` at initial submission.

Reasons:
1. It is not required by COAP for initial submission.
2. It is now marked as an on-request editor-response document.
3. Uploading it proactively draws unnecessary attention to submission history.
4. The cover letter handles the preprint disclosure and concurrent-submission declaration.
5. The portal's editor-only related-work field (if present) handles the remaining disclosure.

**Supply it if:**
- The portal has a mandatory field for related manuscripts
- The editor specifically requests an overlap description
- The editor asks for prior submission history

---

## Content policy if it is supplied

When supplying the statement upon request, use neutral language only:

**Use:** "Earlier unpublished author manuscript; no longer under consideration."  
**Do not use:** "rejected" unless the form explicitly requests the editorial outcome.  
**Do not include:** rejection reasons, reviewer comments, editor names, or decision-letter text.  
**Do include:** shared components, distinct COAP components, and confirmation the prior work is inactive.

The revised `related_manuscripts_statement.tex` applies this policy:
- Predecessor manuscripts are identified by their scientific content (LR-TA predecessor, IPSNS predecessor, Merged framework predecessor, Pre-holdout predecessor) rather than by venue names
- Status: "earlier unpublished author manuscript; no longer under consideration"
- Summary table uses "Inactive" rather than "Rejected"

## How it relates to the cover letter

The cover letter states:
> "No substantially overlapping manuscript is currently under consideration elsewhere. A detailed component-level overlap description can be supplied if requested."

This is the primary disclosure mechanism. The related-manuscript statement is the "detailed component-level overlap description" referenced in that sentence — to be supplied when asked.
