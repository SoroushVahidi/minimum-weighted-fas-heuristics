# COAP and Springer Supplementary Material Requirements

**Sources consulted (2026-06-12):**
- [COAP submission guidelines](https://link.springer.com/journal/10589/submission-guidelines) — Supplementary Information section
- Springer Nature electronic supplementary material guidance (book/journal CMS documents)

| Requirement | Status | Notes |
|-------------|--------|-------|
| Terminology | **Verified** | COAP/Springer use both “Supplementary Information (SI)” and citation label **“Online Resource”** (e.g., “Online Resource 1”) |
| Citation in manuscript | **Verified** | Must cite supplementary files in text like figures/tables |
| Caption per file | **Verified** | Concise caption required; provided in Data Availability and OR1 README |
| PDF for text | **Verified** | Supplementary text/presentations in PDF |
| CSV/XLSX for data | **Verified** | Spreadsheets in standard formats; OR1 uses CSV |
| Author/title in each file | **Verified** | OR1 PDF front matter includes title, authors, affiliation, email |
| Published without copyediting | **Verified** | SI published as received |
| ZIP collection allowed | **Verified** | Multiple files may be collected in `.zip` |
| Code upload | **Not verified as mandatory** | Specialized formats (`.tex`, code) may be supplied; repository upload also encouraged |
| Size limits | **Not verified** | No explicit COAP byte limit found; large downloads discouraged in guidelines |
| Peer review of SI | **Not verified** | Typically reviewed with manuscript; not separately copyedited |
| Bibliography in supplement | **Not verified** | OR1 uses minimal inline bibliography in S3; shares citation keys conceptually with main paper |
