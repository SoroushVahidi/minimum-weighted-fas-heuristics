## Requirements (verified)

| Topic | Rule | Classification |
|---|---|---|
| Terminology | Refer to files as **“Online Resource”** (e.g., Online Resource 1) | Requirement |
| Citation in manuscript | Text must cite supplementary material similarly to figures/tables | Requirement |
| Formats | PDF for text/presentations; CSV/XLSX for spreadsheets; ZIP allowed to collect multiple files | Requirement |
| Front matter | Include article title, journal name, author names, affiliation and e-mail of corresponding author | Requirement |
| Processing | SI published **as received** without conversion, editing, or reformatting | Requirement |
| Peer review | COAP guidelines do not state separate SI peer review; treated as part of submission review | No COAP-specific rule verified beyond general SI policy |
| Copyediting | SI not copyedited per general Springer processing statement | Requirement (general) |
| File-size cap | No COAP-specific published byte limit verified; general guidance warns about large downloads | Recommendation |
| Template | No COAP-specific requirement verified that supplementary PDF must use `sn-article` template | No COAP-specific rule verified |
| Self-contained references | No COAP-specific rule verified; OR1 includes bibliography in supplement for proof citations | No COAP-specific rule verified |

## Artifact compliance

- **Online Resource 1** label and manuscript title/authors on supplement front matter: **yes**
- PDF + ZIP bundle: **yes** (acceptable per “Collecting Multiple Files”)
- Concise caption in declarations: **yes**
- Accessibility: PDF text is selectable; contrast not audited pixel-wise

## Fallback statement

No COAP-specific rule was verified for supplementary PDF journal-template mandate or SI peer-review/copyedit details beyond the general Springer SI statements; the artifact follows current general Springer supplementary-material guidance and COAP’s Online Resource naming convention.
