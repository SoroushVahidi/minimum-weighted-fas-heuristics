# SNCS Cover Letter Draft

Dear Editor,

Please consider the manuscript “An Incumbent-Protected Component-Local Heuristic for Minimum Weighted Feedback Arc Set on Sparse Digraphs” for publication in SN Computer Science.

The manuscript studies the minimum weighted feedback arc set problem on sparse nonnegative weighted directed graphs. It proposes an incumbent-protected strongly connected component local-refinement heuristic that improves feasible vertex orderings through component-local destroy-and-repair moves while accepting only strict global improvements. The work is positioned as a contribution to graph algorithms, combinatorial optimization, heuristic search, and reproducible algorithm engineering.

The evaluation focuses on sparse directed benchmarks and includes comparisons with constructive seeds, graph-ordering baselines, an external executable comparator, an external graph-library baseline, exact and MIP validation on smaller instances, repeated-run comparisons, and a dense LOLIB transfer study used as a scope boundary. On the primary sparse benchmark, the method attains the minimum observed backward weight among the evaluated methods on 96 of 97 standard nonnegative instances. Relative to the better starting seed, it gives 14 strict improvements, 83 ties, and no regressions. On the 57-instance exact-validation subset, the mean optimum-normalized gap is 0.0031\%.

The manuscript is original and is not substantially overlapping with any manuscript currently under consideration elsewhere. An earlier version was submitted to Computational Optimization and Applications and was declined on journal-audience/fit grounds; the present version retargets the same scientific contribution for a broader computer-science algorithms audience.

The accompanying repository and supplementary material provide the code, experiment summaries, and reproducibility artifacts described in the manuscript.

Thank you for considering this submission.
